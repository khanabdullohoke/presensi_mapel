Atur Ulang PIN Presensi
PIN presensi mapel mengikuti PIN presensi staf/guru yang sudah berjalan, sehingga pengaturan ulang dilakukan lewat admin sekolah — bukan otomatis di halaman ini.
  1. Hubungi admin / operator sekolah

    Sampaikan nama lengkap Anda sesuai data pegawai agar identitas dapat diverifikasi.

  2. Verifikasi data guru

    Admin akan mencocokkan nama Anda dengan data pada sistem presensi staf/guru yang sedang berjalan.

  3. PIN baru diberikan / direset oleh admin

    Setelah diverifikasi, admin akan mengatur ulang PIN pada sistem presensi staf/guru. PIN ini otomatis berlaku juga untuk Presensi Mapel Digital.

  4. Masuk kembali dengan PIN baru

    Kembali ke halaman ini, pilih nama Anda, lalu masukkan PIN baru untuk melihat jadwal mengajar hari ini.
